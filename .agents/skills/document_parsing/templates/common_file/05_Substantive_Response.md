# 实质性应标资料

## 提取指引

- **企业证书证明**：通常在资格要求或商务要求章节中，关注营业执照、资质证书、许可证、审计报告等要求
- **拟派人员证书证明**：通常在人员要求或技术要求章节中，关注身份证、职称证、社保证明等要求
- **书面承诺/声明**：通常在投标文件格式或专门的承诺书章节中
- **信用平台查询截图**：通常在资格要求或投标人须知中，关注信用中国、裁判文书网等平台要求
- **厂商授权/检测报告**：通常在技术要求或商务要求章节中

## 提取清单

|  序号 |             提取项             |                      识别指引                     |
| :-: | :-------------------------: | :-------------------------------------------: |
|  1  |            企业证书证明           | 需提供营业执照、企业资质、安全生产许可证、纳税证明、年度财务审计报告、类似业绩证明等的要求 |
|  2  |           拟派人员证书证明          |       需提供身份证、毕业证、职称证、技术资格证、劳动合同、社保证明等的要求      |
|  3  |           书面承诺/声明           |              明确要求投标人提供承诺函/声明函的要求              |
|  4  |          各信用平台查询截图          |          如：需提供信用中国、裁判文书网等平台的查询截图等的要求          |
|  5  | 产品/服务厂商授权、第三方检测报告、其它资质证明资料等 |          如：某些产品需要厂商授权、第三方机构的检测报告等的要求          |
|  6  |          其它实质性应标资料          |                  如有，LLM 自行判断                  |

## 输出示例

```markdown
# 实质性应标资料

## 一、企业证书证明

| 序号 | 证书名称 | 是否必需 | 具体要求 | 备注 |
|------|----------|----------|----------|------|
| 1 | 营业执照 | 是 | 有效的营业执照副本复印件，需加盖公章 | |
| 2 | 企业资质证书 | 是 | 电子与智能化工程专业承包二级及以上资质证书复印件 | |
| 3 | 安全生产许可证 | 是 | 有效的安全生产许可证复印件 | |
| 4 | 纳税证明 | 是 | 近三个月的纳税证明 | |
| 5 | 年度财务审计报告 | 是 | 近三年经审计的财务报告 | |
| 6 | 类似业绩证明 | 是 | 近三年完成的至少3个类似项目的中标通知书、合同及验收证明 | |
| 7 | ISO认证 | 否 | ISO9001质量管理体系认证、ISO27001信息安全管理体系认证 | |

## 二、拟派人员证书证明

| 序号 | 人员类别 | 证书要求 | 是否必需 | 备注 |
|------|----------|----------|----------|------|
| 1 | 项目经理 | 身份证、毕业证、职称证（中级及以上）、二级及以上建造师证书、社保证明、劳动合同 | 是 | |
| 2 | 技术负责人 | 身份证、毕业证、职称证（高级）、社保证明、劳动合同 | 是 | |
| 3 | 安全员 | 身份证、安全员C证、社保证明、劳动合同 | 是 | |
| 4 | 其他技术人员 | 身份证、职称证、社保证明、劳动合同 | 是 | 不少于5人 |

## 三、书面承诺/声明

| 序号 | 承诺函名称 | 是否必需 | 承诺内容 | 备注 |
|------|------------|----------|----------|------|
| 1 | 投标承诺函 | 是 | 承诺投标文件真实有效，无弄虚作假 | |
| 2 | 无重大违法记录声明 | 是 | 声明近三年无重大违法记录 | |
| 3 | 廉洁承诺函 | 是 | 承诺遵守廉洁纪律，不贿赂 | |
| 4 | 保密承诺函 | 否 | 承诺对招标文件内容保密 | |

## 四、各信用平台查询截图

| 序号 | 平台名称 | 是否必需 | 查询要求 | 截图时间要求 |
|------|----------|----------|----------|--------------|
| 1 | 信用中国 | 是 | 无失信被执行人、重大税收违法案件当事人等记录 | 投标截止日前3天内 |
| 2 | 中国政府采购网 | 是 | 无政府采购严重违法失信行为记录 | 投标截止日前3天内 |
| 3 | 裁判文书网 | 否 | 无重大违法诉讼记录 | 投标截止日前3天内 |

## 五、产品/服务厂商授权、第三方检测报告

| 序号 | 资料名称 | 是否必需 | 具体要求 | 备注 |
|------|----------|----------|----------|------|
| 1 | 核心产品厂商授权 | 是 | 所投核心产品需提供厂商授权书 | |
| 2 | 第三方检测报告 | 是 | 核心产品需提供近一年的第三方检测报告 | |
| 3 | 软件著作权证书 | 否 | 自主开发软件需提供软件著作权证书 | |

## 六、其它实质性应标资料

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求
```
