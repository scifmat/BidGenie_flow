# 基础信息

## 提取指引

- **项目编号/项目名称**：通常出现在招标文件首页、招标公告标题中
- **采购方式/组织形式**：通常在投标人须知或招标公告中明确说明
- **预算金额/最高限价**：通常在招标公告或投标人须知前附表中
- **投标截止时间/开标地点**：通常在招标公告或投标人须知中
- **采购单位/代理机构**：通常在招标公告或联系方式章节中
- **保证金相关**：通常在投标人须知或专门的保证金条款中
- **分散信息汇总**：项目概况、合同履行期限等信息可能分散在多处，需汇总提取

## 提取清单

### 1. 项目信息

|  序号 |     提取项     | 是否必填 |                说明                |
| :-: | :---------: | :--: | :------------------------------: |
|  1  |     项目编号    |  必填  |     如 WHZC-2025-00200-GK00136    |
|  2  |     项目名称    |  必填  |              完整项目名称              |
|  3  |     项目概况    |  选填  |           原文或 LLM 简洁总结           |
|  4  |     采购方式    |  选填  | 公开招标/邀请招标/竞争性谈判/竞争性磋商/询价采购/单一来源等 |
|  5  |     组织形式    |  选填  |             分散采购/集中采购            |
|  6  |    合同履行期限   |  选填  |              <br />              |
|  7  |    所属行业划分   |  选填  |           如：软件和信息技术服务业           |
|  8  |  是否接受联合体投标  |  选填  |                是/否               |
|  9  |  是否可采购进口产品  |  选填  |                是/否               |
|  10 |   是否接受合同分包  |  选填  |                是/否               |
|  11 | 是否专门面向中小微企业 |  选填  |                是/否               |
|  12 |  面向中小微企业的类型 |  选填  |             如面向则注明类型             |
|  13 |   是否组织现场踏勘  |  选填  |                是/否               |

### 2. 资金与限价

|  序号 |  提取项 | 是否必填 |       说明       |
| :-: | :--: | :--: | :------------: |
|  1  | 预算金额 |  必填  | 总预算，注明单位（万元/元） |
|  2  | 最高限价 |  选填  |   如有，注明金额和单位   |
|  3  | 资金来源 |  选填  |    财政性资金/自筹等   |

### 3. 保证金相关

|  序号 | 子提取项 |        说明        |
| :-: | :--: | :--------------: |
|  1  | 是否提交 |        是/否       |
|  2  | 提交金额 |      如提交则注明      |
|  3  | 提交期限 |      如提交则注明      |
|  4  | 提交方式 | 如提交则注明（银行转账/保函等） |
|  5  | 是否退还 |      如提交则注明      |
|  6  |  备注  |       补充说明       |

**保证金提取注意事项：**
 - 保证金按不同类别分类，一种保证金一个表格
 - 只提取需要提交的保证金信息 

### 4. 时间与地点

|  序号 |     提取项    | 是否必填 |      说明     |
| :-: | :--------: | :--: | :---------: |
|  1  |   获取文件时间   |  选填  |    注明起止时间   |
|  2  |   投标截止时间   |  必填  |    投标截止时间   |
|  3  |    开标时间    |  必填  |     开标时间    |
|  4  |    开标地点    |  选填  | 线上投标注明平台及网址 |
|  5  |    投标有效期   |  选填  |    <br />   |
|  6  | 合同履行期限/服务期 |  选填  |    <br />   |

### 5. 组织单位与联系

|  序号 |   提取项  | 是否必填 |          说明         |
| :-: | :----: | :--: | :-----------------: |
|  1  |  采购单位  |  必填  | 名称、地址、联系人、电话、邮箱（如有） |
|  2  |  代理机构  |  选填  | 名称、地址、联系人、电话、邮箱（如有） |
|  3  | 项目联系方式 |  选填  |   如有，联系人、电话、邮箱（如有）  |
