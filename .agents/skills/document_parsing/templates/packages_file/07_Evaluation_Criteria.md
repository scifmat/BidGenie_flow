# 评审标准

## 提取指引

- **评分标准**：通常在招标文件专门的"评标办法"、"评审标准"、"评分办法"章节中
- **表格提取**：评分标准通常以表格形式呈现，包含评分因素、分值、评分标准等列
- **商务/技术分离**：注意区分商务评分标准和技术评分标准，分别提取
- **分标段差异**：多个标段的评分办法可能通用也可能不同，如通用则重复提取

## 提取清单

|  序号 |    提取项    |                  说明                  |
| :-: | :-------: | :----------------------------------: |
|  1  | 报价/商务评分标准 |          一般与技术评分标准在一个表内，带分值的         |
|  2  |   技术评分标准  |          一般与技术评分标准在一个表内，带分值的         |
|  3  |    评标办法   | 几个标段之间的评分办法可能通用也可能不通用，通用则每个标段提取一样的内容 |

## 输出示例

```markdown
# 评审标准

## 一、评标办法

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求

## 二、商务评分标准

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求

## 三、技术评分标准

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求

## 四、报价评分标准

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求
```
