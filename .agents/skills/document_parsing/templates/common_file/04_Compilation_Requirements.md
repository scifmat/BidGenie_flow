# 投标文件编制要求

## 提取指引

- **投标文件格式**：通常在招标文件专门的"投标文件格式"章节中，包含目录结构要求
- **编制要求**：通常在投标人须知或投标文件格式章节中，关注排版、封装、签章、签字、密封等要求
- **格式细节**：包括纸张大小、字体要求、页码要求、电子版要求等

## 提取清单

|  序号 |    提取项   |          识别指引         |
| :-: | :------: | :-------------------: |
|  1  |  投标文件格式  | 招标文件中注明的投标文件内容组织结构的格式 |
|  2  | 投标文件编制要求 | 包括但不限于排版、封装、签章、签字、密封等 |

## 输出示例

```markdown
# 投标文件编制要求

## 一、投标文件格式

投标文件应包含以下内容，按顺序编排：

1. 投标函及投标函附录；
2. 法定代表人身份证明或授权委托书；
3. 投标保证金缴纳证明；
4. 技术方案（含技术响应表）；
5. 商务偏离表；
6. 报价函及明细报价表；
7. 资格证明文件；
8. 其他材料。

## 二、投标文件编制要求

### 2.1 排版要求

- 纸张大小：A4纸；
- 字体：正文宋体小四，标题黑体四号；
- 行距：1.5倍行距；
- 页码：每页右下角标注页码，格式为"第X页/共Y页"；
- 目录：投标文件需包含详细目录，标注各章节页码。

### 2.2 封装要求

- 投标文件需分为技术部分、商务部分、报价部分，分别装订；
- 每部分需单独密封，密封袋上需注明项目名称、项目编号、投标人名称及"技术部分/商务部分/报价部分"字样；
- 密封袋封口处需加盖投标人公章。

### 2.3 签章要求

- 投标文件每页需加盖投标人公章；
- 投标函、法定代表人身份证明需由法定代表人签字并加盖公章；
- 授权委托书需由法定代表人签字、被授权人签字并加盖公章；
- 关键页需加盖骑缝章。

### 2.4 电子版要求

- 电子版投标文件需为PDF格式，与纸质版内容一致；
- 电子版文件需刻录至光盘或U盘，单独密封提交；
- 文件命名格式："项目编号_投标人名称_投标文件.pdf"。
```
