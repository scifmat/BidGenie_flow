# 采购内容

## 提取指引

- **采购内容**：通常在招标文件专门的"采购内容"、"招标范围"、"项目需求"章节中
- **分标段提取**：如项目分标段，每个标段的采购内容需单独提取
- **原文保留**：采购内容应尽量原封不动地提取，保持完整性和准确性
- **附件关联**：注意采购内容可能引用其他附件（如采购清单、技术规格书等）

## 提取清单

|  序号 |  提取项 |                        识别指引                       |
| :-: | :--: | :-----------------------------------------------: |
|  1  | 采购内容 | 招标文件中有专门章节，须原封不动地将所属各标段的采购内容提取出来，未分标段时，直接提取项目采购内容 |

## 输出示例

```markdown
# 采购内容

## 一、标段信息

- 标段编号：01
- 标段名称：XX市智慧城市综合管理平台建设项目（一期）

## 二、采购内容

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求
```
