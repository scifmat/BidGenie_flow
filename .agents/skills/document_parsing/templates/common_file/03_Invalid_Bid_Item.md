# 无效投标项

## 提取指引

- **废标情形/无效投标情形**：这些条款通常分散在招标文件各处（投标人须知、评标办法、技术要求等）
- **关键词识别**：关注"废标"、"无效"、"否决投标"、"不得存在"、"禁止"等关键词
- **汇总提取**：将所有分散的相关条款汇总到本文件中，按类别整理
- **条款编号**：建议保留原文条款编号，便于后续核对

## 提取清单

|  序号 |   提取项   |         识别指引        |     特殊说明    |
| :-: | :-----: | :-----------------: | :---------: |
|  1  |   废标情形  |    招标文件中注明"废标"的条款   | 分散在文件各处，须汇总 |
|  2  |  无效投标情形 | 招标文件中注明"无效"等否决投标的条款 | 分散在文件各处，须汇总 |
|  3  | 不得存在的情形 | 招标文件中注明"不得存在的情形"的条款 | 分散在文件各处，须汇总 |

## 输出示例

```markdown
# 无效投标项

## 一、废标情形

1. 投标截止时间后送达的投标文件；
2. 投标文件未按规定密封的；
3. 投标人未按要求提交投标保证金的；
4. 投标文件中附有招标人不能接受的条件的；
5. 评标委员会认定投标人串通投标或弄虚作假的。

## 二、无效投标情形

1. 投标文件未加盖单位公章或未由法定代表人或其授权代表签字的；
2. 投标文件关键内容不全或字迹模糊无法辨认的；
3. 投标人递交两份或多份内容不同的投标文件，未声明哪一份有效的；
4. 投标报价超过最高限价的；
5. 投标有效期不足的；
6. 资格证明文件不全或不符合要求的；
7. 未按招标文件规定的格式填写投标文件的。

## 三、不得存在的情形

1. 单位负责人为同一人或者存在直接控股、管理关系的不同供应商，不得同时参加本项目投标；
2. 投标人不得与招标人、招标代理机构或其他投标人串通投标；
3. 投标人不得以他人名义投标或以其他方式弄虚作假骗取中标；
4. 投标人不得提供虚假材料谋取中标；
5. 近三年内存在重大违法记录的投标人不得参加投标。
```
