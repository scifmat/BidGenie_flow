# 资格审查

## 提取指引

- **投标人的资格要求**：通常在"投标人须知"或专门的"投标人资格条件"章节中
- **符合性审查**：通常在评标办法或评审标准章节中，关注"符合性检查"、"初步评审"等关键词
- **资格性审查**：通常在评标办法或评审标准章节中，关注"资格审查"、"资格性检查"等关键词
- **分散信息汇总**：资格要求可能分散在招标文件多个章节，需汇总提取

## 提取清单

|  序号 |    提取项   |                识别指引               |
| :-: | :------: | :-------------------------------: |
|  1  | 投标人的资格要求 | 招标文件一般会注明"投标人/申请人/供应商...的资格要求"等字样 |
|  2  |   符合性审查  |      招标文件一般会有专门章节注明符合性审查相关条款      |
|  3  |   资格性审查  |      招标文件一般会有专门章节注明资格性审查相关条款      |

## 输出示例

```markdown
# 资格审查

## 一、投标人的资格要求

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求

## 二、符合性审查

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求

## 三、资格性审查

> 根据招标文件或附件样式进行排版，此处不做具体展示样式要求
```
