# 技术服务要求

## 提取指引

- **技术服务要求**：通常在招标文件专门的"技术要求"、"技术规格"、"服务要求"章节中
- **技术参数**：关注设备参数、性能指标、技术标准等要求
- **技术能力**：关注投标人的技术实力、研发能力等要求
- **服务内容**：关注服务范围、服务期限、服务响应时间等要求
- **分标段差异**：不同标段的技术要求可能不同，需分别提取

## 提取清单

|  序号 |   提取项  |                   说明                  |
| :-: | :----: | :-----------------------------------: |
|  1  | 技术服务要求 | 一般招标文件会注明技术服务要求相关条款，如：技术要求、技术能力、技术服务等 |
