# 商务要求

## 提取指引

- **商务要求**：通常在招标文件专门的"商务要求"、"投标人资格"、"商务条款"章节中
- **企业资质**：关注企业营业执照、资质证书、认证证书等要求
- **人员资质**：关注拟派人员的职称、学历、工作经验等要求
- **业绩要求**：关注类似项目业绩、完成时间、合同金额等要求
- **财务要求**：关注财务状况、审计报告、纳税证明等要求

## 提取清单

|  序号 |  提取项 |                       说明                      |
| :-: | :--: | :-------------------------------------------: |
|  1  | 商务要求 | 一般招标文件会注明商务要求相关条款，如：企业资质、人员资质、服务要求、业绩要求、财务要求等 |

## 输出示例

```markdown
# 商务要求

## 一、企业资质要求

| 序号 | 资质类型 | 是否必需 | 具体要求 | 证明材料 |
|------|----------|----------|----------|----------|
| 1 | 营业执照 | 是 | 有效的营业执照副本 | 营业执照复印件 |
| 2 | 企业资质证书 | 是 | 电子与智能化工程专业承包二级及以上 | 资质证书复印件 |
| 3 | 安全生产许可证 | 是 | 有效的安全生产许可证 | 许可证复印件 |
| 4 | ISO9001认证 | 否 | 质量管理体系认证证书 | 认证证书复印件 |
| 5 | ISO27001认证 | 否 | 信息安全管理体系认证证书 | 认证证书复印件 |

## 二、人员资质要求

### 2.1 项目经理

| 要求项 | 具体要求 | 是否必需 |
|--------|----------|----------|
| 执业资格 | 二级及以上建造师（机电工程或市政公用工程专业） | 是 |
| 职称 | 中级及以上职称 | 是 |
| 经验 | 5年以上类似项目管理经验 | 是 |
| 在建情况 | 无在建项目 | 是 |

### 2.2 技术负责人

| 要求项 | 具体要求 | 是否必需 |
|--------|----------|----------|
| 职称 | 高级工程师职称 | 是 |
| 经验 | 8年以上类似项目技术管理经验 | 是 |
| 专业能力 | 熟悉智慧城市相关技术和标准 | 是 |

### 2.3 其他人员

| 岗位 | 数量要求 | 资质要求 | 是否必需 |
|------|----------|----------|----------|
| 软件工程师 | 不少于5人 | 相关专业证书 | 是 |
| 硬件工程师 | 不少于2人 | 相关专业证书 | 是 |
| 测试工程师 | 不少于2人 | 相关专业证书 | 是 |

## 三、业绩要求

| 要求项 | 具体要求 | 是否必需 |
|--------|----------|----------|
| 业绩数量 | 近三年完成至少3个类似项目 | 是 |
| 项目金额 | 单个项目合同金额不低于500万元 | 是 |
| 证明材料 | 中标通知书、合同及验收证明 | 是 |
| 时间范围 | 2022年1月1日至今 | 是 |

## 四、财务要求

| 要求项 | 具体要求 | 是否必需 |
|--------|----------|----------|
| 财务状况 | 近三年无亏损 | 是 |
| 审计报告 | 提供近三年经审计的财务报告 | 是 |
| 流动资金 | 具有足够的流动资金承担本项目 | 是 |

## 五、服务要求

| 服务类型 | 具体要求 | 备注 |
|----------|----------|------|
| 质保期 | 2年，质保期内免费维护 | |
| 技术支持 | 7×24小时，响应时间不超过2小时 | |
| 培训服务 | 免费培训，不少于20人次 | |
| 质保期后服务 | 提供优惠的维护服务 | 具体价格另行协商 |

## 六、付款方式

| 付款阶段 | 付款比例 | 付款条件 | 备注 |
|----------|----------|----------|------|
| 预付款 | 30% | 合同签订后15个工作日内 | |
| 进度款 | 30% | 系统开发完成并通过初验后 | |
| 验收款 | 30% | 系统上线试运行并通过终验后 | |
| 质保金 | 10% | 质保期满后 | |
```
